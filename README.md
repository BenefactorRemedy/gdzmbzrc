# SC-PRIORITY-DEMO-LITE RU v2.2

Проект для распределения ограниченного запаса (stock) между заказами с приоритетами (A/B/C) и поддержкой стратегий дефицита (СЕРВИС vs ПРОСТОТА).

## Структура
- `/src` - Исходный код (парсинг, валидация, логика)
- `/tests` - Тесты
- `/docs` - Документация

**Примечание:** Это начальный коммит для инициализации ветки.
