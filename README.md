## ABC Анализ для Supply Chain Management

Система для работы с запросами по ABC анализу для управления цепями поставок (Supply Chain).

### Возможности

- 📊 **Автоматическая классификация** товаров на категории A, B, C
- 📈 **Детальная аналитика** по каждому товару и категории
- 🎯 **Рекомендации** по управлению запасами
- 🔍 **Фильтрация и поиск** по категориям
- 📋 **Сводная статистика** по всем категориям
- ⚙️ **Настраиваемые пороги** классификации

### Быстрый старт

```python
from abc_analysis import Product, SupplyChainABCRequest

# Создание списка товаров
products = [
    Product("SKU001", "Компьютер", 50, 1500.0),
    Product("SKU002", "Монитор", 120, 300.0),
    Product("SKU003", "Клавиатура", 500, 50.0),
]

# Выполнение ABC анализа
handler = SupplyChainABCRequest()
report = handler.process_inventory_analysis(products)

# Вывод результатов
for result in report['results']:
    print(result)
```


### Типы запросов

1. **Полный анализ инвентаря** - комплексный анализ всех товаров
2. **Фильтрация по категориям** - получение товаров категории A, B или C
3. **Топ товаров** - получение N самых ценных товаров
4. **Сводная статистика** - детальная статистика по категориям
