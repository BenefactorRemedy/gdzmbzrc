- ✅ Полное выполнение (100%)
- ✅ Основные метрики
- ✅ Идеально для первого знакомства!

**Команда напрямую:**
```bash

  --q1 "ORD001|SKU-A|100|A|-" \
  --q2 "SKU-A|150"
```

## Или введите свои данные

### Интерактивный режим
```bash
python -m src.main --interactive
```

Система спросит:
1. Q1: Заказы (OrderID|SKU|Qty|Class|Date)
2. Q2: Остатки (SKU|Qty)
3. Q3: Частичная отгрузка? (YES/NO)
4. Q4: Резервы (SKU|Reserved или пусто)
5. Q5: Сортировка по дате? (YES/NO)
6. Q6: Режим сервис? (YES/NO)

### Командная строка
```bash
python -m src.main \
  --q1 "ORD001|SKU-A|100|A|-" \
  --q2 "SKU-A|150" \
  --q3 YES
```

## Формат данных

### Заказы (Q1)
```
OrderID|SKU|Qty|Class|DueDate
ORD001|SKU-A|100|A|2026-02-15
ORD002|SKU-B|50|B|-
```

- **OrderID**: уникальный ID заказа
- **SKU**: код товара
- **Qty**: количество (должно быть > 0)
- **Class**: приоритет (A, B или C)
- **DueDate**: дата поставки (YYYY-MM-DD или "-")

### Остатки (Q2)
```
SKU|Qty
SKU-A|500
SKU-B|200
```

### Резервы (Q4)
```
SKU|Reserved
SKU-A|50
```

Или просто "-" если резервов нет.

## Ожидаемый результат

Каждый пример выводит:

1. **Статус**
   - ✅ SUCCESS (успешно)
   - ⚠️ WARN (с предупреждениями)
   - 🛑 STOP (критические ошибки)

2. **Входные данные**
   - Таблица заказов
   - Таблица остатков
   - Настройки Q3-Q6

3. **Результаты**
   - Таблица распределения
   - Для каждого заказа: запрошено/выделено/fill rate

4. **Метрики**
   - Fill Rate (%)
   - Zero Count (количество нулевых)
   - Risk Level (🟢 GREEN / 🟡 YELLOW / 🔴 RED)
